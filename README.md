## 我关注的工作

- **问题定义**：用户正在完成什么任务，现有流程卡在哪里，为什么值得引入 AI。
- **方案取舍**：明确工具调用、知识检索和人工确认各自的边界。
- **评测与迭代**：保留失败样例，比较方案，说明指标口径和当前限制。
- **工程交付**：让核心流程可以复现，失败有清楚反馈，改动有测试依据。

当前在完善两个 AI 项目的可复现流程与评测证据。学习练习与 fork 保留原本的来源和定位。
